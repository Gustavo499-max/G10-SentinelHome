
# Contribuindo com G10 SentinelHome

Obrigado pelo interesse em contribuir!

## Como contribuir

1. Faça um fork do repositório.
2. Crie uma branch para sua alteração.
3. Implemente a melhoria.
4. Execute os testes.
5. Envie um Pull Request.

## Padrão de branches

- feat: novas funcionalidades
- fix: correções
- docs: documentação
- refactor: refatoração
- test: testes

## Padrão de commits

Utilizamos Conventional Commits.

Exemplo:

feat: add device monitoring endpoint

fix: correct fuzzy risk classification

docs: update installation instructions

## Qualidade

Toda alteração deve ser acompanhada de testes quando aplicável.

Pull Requests devem apresentar uma descrição clara das alterações.
